# openclare PRO

The professional edition of [openclare](https://github.com/marcgardent/openclare), the automatic
quad retopology add-on for Blender.

openclare's engine is open source and stays so: every algorithm, in the Community and in the PRO
edition, is in the public repository, under the GPL-3.0-or-later. openclare PRO adds to the
Community add-on what production asks for: artistic control over the flow and the loops, live
diagnostics in the viewport, batch work and integration in a pipeline.

This repository holds the website, the documentation and the support tickets of openclare PRO.
It is being set up: nothing is for sale yet.

- The Community add-on and the engine: <https://github.com/marcgardent/openclare>
- Support for openclare PRO: the [issues](../../issues) of this repository.
